Project Planning

House Vibe Site Plan

Site Name

House Vibe

The name House Vibe represents the energy, rhythm, and feeling of House music.

Site Purpose

House Vibe is a music discovery website where visitors can explore House music artists, tracks, genres, and countries. Visitors can search for music and save their favorite selections.

Target Audience

The website is designed for people who enjoy House music and want an easy way to discover different artists, genres, and tracks.

Site Goals

  • Help visitors discover House music.
  • Display music information dynamically.
  • Allow visitors to search and filter music.
  • Allow visitors to save favorite music.
  • Provide a simple and responsive experience.

Color Scheme

The primary background color is dark charcoal #111111.

The accent color is bright lime #D9FF3F.

White is used for primary text and light gray is used for supporting text.

Typography

The website uses Poppins for headings, navigation, buttons, and body text.

Pages

Home

Introduces House Vibe and provides a call-to-action leading visitors to the music collection.

Discover

Displays music data dynamically from a JSON file. Visitors can search, filter by genre, view details, and save favorites.

Favorites

Displays music saved by the visitor using localStorage.

Wireframe Description

On mobile devices, the navigation uses a hamburger menu and content is displayed in a single column. On larger screens, the navigation becomes horizontal and music cards are displayed in multiple columns.
